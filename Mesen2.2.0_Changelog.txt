2.2.1 Hotfix:
NES:
- CHR-RAM: Fixed CHR-RAM setup when loading iNES ROMs that are present in the NES database (Fiskbit)


Full changelog for Mesen 2.2.0 (compared to Mesen 2.1.1):

GB:
- GB: Added link cable support for two GB or GBC consoles (Nova)
- GB: Fixed serial clocking regression (fixes Shin Megami Tensei: Devil Children: Kuro no Sho in GB/SGB modes) (paulb_nl)
- GBC: Fixed HDMA pending bug (Championship Motocross 2001 Featuring Ricky Carmicheal) (paulb_nl, TakuikaNinja)
- GBC: Added palette to memory viewer (Nova)
- SGB: Fixed $7001-$700F acknowledging packets when they shouldn't (Nova)
- Tilemap viewer: Fixed undefined behavior issue affecting Windows builds (Sour)
- General: Added new "best" model selection option to pick the best model a game explicitly supports (Fiskbit)

GBA:
- CPU: Fixed SWP operation order (fixes data_swap test) (Sour)
- DMA: Fixed DMA never running when constantly re-triggered before it can start (fixes Hades-Tests/dma-latch test) (Sour)
- Flash: Switched to move common 128 KiB flash ID, implemeneted basic read/write timings (CasualPokePlayer)
- RTC: Changed to not use local time, to fix DST bug (fixes Rockman EXE 4.5) (Fiskbit)
- Serial: Improved serial timings (fixes serial timing tests) (CasualPokePlayer)
- Debugger: Fixed CPSR value not updating when mode changes (Sour)
- Tilemap viewer: Fixed incorrect addresses for tiles in 512x256 background layers without matrix transforms (CharlesVanEeckhout)
- Disassembler: Fixed swapped LDSB and LDRH instructions in thumb mode (Sour)
- General: Added save type override for Rockman EXE 4.5, which had incorrect save type detection (Fiskbit)

NES:
- CPU: Fixed overclocking to not invert get/put cycles, improving compatibility with DMA-synced accesses (Sour)
- CPU: Fixed IRQ polling in branch instructions (Fiskbit)
- CPU: Fixed dummy read behavior for various instructions (100th Coin, Fiskbit)
- CPU: Fixed open bus behavior when memory accesses are isolated to the internal or external CPU buses (Fiskbit)
- CPU: Fixed external open bus contents after DMA/joypad bus conflict (Fiskbit)
- CPU: Fixed DMA so it can read from non-readable 2A03-range addresses (allows DMA reading Rainbow's $4011 IPCM register) (Fiskbit)
- CPU: Fixed a DMC DMA timing bug that could make DMA occur one cycle too early (flipping parity) at the end of the frame or when stepping back (Fiskbit, Sour)
- CPU: Fixed H / late-G DMC DMA to not require a 1 APU cycle gap between DMC DMAs (Fiskbit)
- CPU: Fixed H / late-G DMC DMA so that two DMC DMA's back-to-back can each trigger an extra joypad clock with non-HVC-001 behavior (Fiskbit)
- CPU: Improved mapper read performance (Sour)
- PPU: Changed $2004 increment behavior when written during rendering (100th Coin)
- PPU: Fixed $2004 writes so they are reads when OAM1ADDR wraps around (100th Coin)
- PPU: Added a delay before $2007 writes take effect (100th Coin)
- PPU: Fixed high background plane shift register to bring in 1's (100th Coin)
- PPU: Changed AT fetches during sprite fetch to NT fetches and fixed Rainbow and MMC5 to match (100th Coin, Fiskbit, Broke Studio)
- PPU: Fixed dot 257 fetch to use the correct v (100th Coin)
- PPU: Added RGB emphasis when using RGB PPUs (Fiskbit)
- PPU: Changed OAM decay to persist the current OAM1ADDR row while rendering is disabled (Fiskbit)
- PPU: Changed OAM to decay after about 40 scanlines instead of 26 (fixes Battletoads, which needs about 37) (Fiskbit)
- PPU: Improved OAM address handling during sprite rendering (Fiskbit)
- PPU: Improved OAM corruption emulation (Fiskbit)
- PPU: Limited OAM corruption to NTSC and Dendy PPUs (except $2003 write corruption on Dendy) (Fiskbit)
- PPU: Reimplemented PAL forced OAM refresh to match hardware behavior (Fiskbit)
- PPU: Improved sprite rendering (sprite shifters, scanline 0 sprites, shifter counting delay) (Fiskbit, Sour)
- EPSM: Fixed EPSM device not responding for a while after reset (Sour)
- FDS: Updated most of the debug labels and descriptions (TakuikaNinja)
- FDS: Significantly improved accuracy to match new research (TakuikaNinja)
- FDS: Improved performance 25-30% when using automatic disk switching (Sour)
- CHR-NVRAM: Improved CHR-NVRAM handling so that conformant NES 2.0 headers with one CHR-RAM type get that type (Fiskbit, Sour)
- BNROM: Enabled bus conflicts (Sour)
- Mapper 16: Fixed to use actual save RAM size instead of always using the header's (fixes mapper 16 iNES ROMs with EEPROM when using database) (Sour)
- Mapper 132: Fixed the read mask to be $E100 instead of $E103 (fixes Creatom) (infval)
- Mapper 168: Fixed CHR-NVRAM handling to give the correct amount of CHR-RAM and only save/load the NVRAM portion (fixes RacerMate Challenge II) (Fiskbit, Sour)
- Mapper 180: Added support for oversize PRG banking (Heemin)
- Mapper 183: Reimplemented as a VRC4e variant (fixes Shui Guan Pipe) (Fiskbit)
- MMC3: Fixed mirroring state in register viewer (Fiskbit)
- MMC5: Improved scanline IRQ behavior (Sour)
- MMC5: Fixed edge cases in vertical split behavior (Sour)
- MMC5: Added PCM read mode support (Heemin, Fiskbit)
- MMC5: Improved MMC5 and expansion audio mapper performance (Sour)
- MMC5: Improved MMC5 PCM mixing to avoid clipping (Zeta)
- Namco 108: Fixed register range & allowed random power on register state (lidnariq)
- Namco 108: Fixed submapper support (TakuikaNinja)
- Namco 163: Added audio RAM to debug tools as mapper RAM (Sour)
- Namco 163: Fixed PRG-RAM banking when no battery is present (lidnariq)
- Namco 163: Fixed auto-increment to not wrap past $7F (Heemin)
- Namco 340: Fixed mirroring by unswapping horizontal and screenB (fixes Dream Master when configured for the correct mapper 210 submapper 2) (awjackson)
- NINA-002: Added support for this board (not used by any contemporary games) and for oversize PRG/CHR banking (Heemin)
- NSF: Fixed to use emulator region instead of NSF header region (TakuikaNinja)
- Rainbow: Fixed window behavior when ext. mode is not enabled (Sour)
- Rainbow: Added CPU parity register (Zeta)
- Rainbow: Added scanline counter read register (Zeta)
- Rainbow: Added CIRAM selection for CHR patterns (Zeta)
- RAMBO-1: Fixed initial state (TakuikaNinja)
- SUNSOFT-1: Fixed upper CHR slot to force banks 4-7 (Fiskbit, Broke Studio)
- VRC2: Fixed 1-bit latch range to be $6000-$6FFF instead of $6000-$7FFF (Fiskbit)
- VRC4: Added VRC4f support (fixes World Hero) (Fiskbit)
- Vs. System: Added DIP switches for games not in the database (Fiskbit)
- Controller: Added NTT Data Keypad (Nova)
- Database: Changed to support byte sizes instead of truncating to KB (Sour)
- Database: Fixed Dream Master to be mapper 210 submapper 2 (Fiskbit)
- Database: Fixed Huge Insect to use horizontal mirroring (Fiskbit)
- Debugger: Fixed frame IRQ from being acked by predictive breakpoints on $4015 (Fiskbit, Sour)
- Event viewer: Fixed crash when stepping back while 'Show NTSC borders' is enabled (Sour)
- Header editor: Changed to keep emulation paused if opened without debug tools open (Sour)
- Header editor: Added support for non-KB sizes (Sour, Fiskbit)
- Header editor: Changed to work with archived and soft-patched ROMs (Sour)
- Log window: Changed to print sizes in bytes if not a multiple of 1024 (Fiskbit)
- Log window: Added CHR save RAM size log if nonzero (Fiskbit)
- Tilemap viewer: Fixed 'Changes' highlight type, which was nonworking (Sour)
- HD Packs: Fixed ogg playback when using runahead (works for runahead = 1; is playable but can miss sound triggers with larger values) (Sour)
